# thelonious-punk
Early (2024) code for the Thelonious Punk jazz agent: it reads jazz news feeds (JazzTimes, All About Jazz, DownBeat), keeps a narrative state and writes in a voice. Cleaned for release: keys removed, the narrative engine is a stub you implement.

```
pip install -r requirements.txt
export OPENAI_API_KEY=...   # never commit it
python TPUNK.py
```
Original private history is receipted; the public 2024 repository is [CHECKPOINT](https://github.com/nebulamji/CHECKPOINT).

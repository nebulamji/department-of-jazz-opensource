# Department of Jazz: open tools

Open-source building blocks for jazz musicians, teachers and the agents that work for them. Utility and infrastructure. Nothing here is an investment product.

| Package | What it is |
|---|---|
| [`harmonic-lineage`](packages/harmonic-lineage) | Pitch to light: note frequency, octave-folded into the visible band, converted with the CIE 1931 tables. Also RTTY (ITA2) and the JS8-style tone rule. Pure functions, no dependencies. |
| [`bass-engine`](packages/bass-engine) | A jazz bass-line engine: chord-tone voice leading, chromatic approach, fingerboard position ranges. Bring your own chord source. |
| [`thelonious-punk`](packages/thelonious-punk) | The jazz-news agent: reads jazz feeds and writes in a voice. Early (2024) code, cleaned. |
| [`mix-engine`](packages/mix-engine) | An agentic mixing toolkit: a Logic Pro MCP server, an accessibility-API daemon, a MIDI Scripter bridge and a Suno agent. |

## What is not here, on purpose
Hosted services, prompts and datasets of third-party music stay behind our API. Artwork seeds and game systems for JazzCats are separate. This repository is code you can read, run and change.

## 2024 provenance
Early work is public with GitHub's own commit dates: [mji-frontend](https://github.com/nebulamji/mji-frontend), [lvc](https://github.com/nebulamji/lvc), [CHECKPOINT](https://github.com/nebulamji/CHECKPOINT). Keys and personal details were removed; dates were not.
